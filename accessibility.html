Accessibility Statement

Last updated: October 22, 2026

scampedia.net is owned and operated by Verify Guard Apps LLC (Louisiana). Scam warnings only help if everyone can read them, so we want this site to work for people who use screen readers, keyboards, magnification, or other assistive technology.

Our goal

We're working toward the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA for this site. That's a goal, not a claim: we haven't had the site independently audited, and we don't claim it fully meets that standard today.

Last review

We last reviewed this site on October 22, 2026. That review was an automated scan of the home page, the scam database, a sample scam entry, the Learn pages, and our policy pages with the axe-core accessibility checker, plus a manual check of alt text, color contrast, heading order, keyboard navigation, focus outlines, and the "Report a Scam" form. We fixed what it found that we could fix right away, including heading order on the Learn page, a link that only differed from nearby text by color, and a search box with a faint focus outline. We haven't yet tested the site with people who use assistive technology day to day.

Known limitations

  • Emoji. Many headings, category labels, and cards use emoji, and some screen readers read them out by name (for example, "money bag").
  • The scam database needs JavaScript. The searchable list on the Scam Database page is built in your browser with JavaScript. If JavaScript is off, every entry is still available as a plain page from the A–Z list.
  • "Report a Scam" form labels. The form's fields have labels that screen readers announce, but on screen the only label is grey hint text inside the box, which disappears once you start typing.
  • Sources we link to. Each entry links to the news, government, and company pages it cites. We don't control those sites and can't vouch for their accessibility.

Get help or another format

If you have trouble using any part of this site, or you'd like an entry or policy page in another format, email verifyguardsupport@gmail.com. Tell us which page and what went wrong, and what format would work for you. We aim to reply within 2 business days.
